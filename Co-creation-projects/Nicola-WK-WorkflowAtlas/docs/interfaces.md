# Frozen interface contract v1

## 2026-11-12 multi-platform file import

`POST /api/import/file`, `/api/import/preview`, `/api/import/commit` share `format=auto|json|jsonl|csv|txt|html`, default `auto`. Preflight detection reports the actual format without `auto`. CSV includes tab-delimited exports. Existing source/timezone/fingerprint and partial-confirmation semantics apply to every format. UTF-8, BOM-marked UTF-16/32 and strict GB18030/GBK decoding run before shared format parsing. No replacement characters are inserted on decoding failures.

`StandardMessage.source_type` extends existing values with `wechat`, `qq`, and `chat`. Existing standardized and Feishu normalized records retain their previous structure. Platform exporters use deterministic field aliases and recognized container metadata, retaining original raw records, source-native identities when present and selected-timezone behavior. Export formats lacking native IDs may carry an explicitly derived local import identity and warning. Original timestamps remain required. Canonical API messages continue to require an explicit ID and timezone.

`connectors.formats.source_contexts(content,format)` returns a mapping of SHA-256 to original file-level export context, excluding message arrays. Metadata stores `import.source_context_hash` plus compact sender context. `Repository.import_messages(messages,source_id,import_contexts=None)` persists messages and source contexts in one transaction. Context payloads live under `import_context:<source_id>:<hash>` and include source_id, context_hash and context. Deletion clears exact-source context payloads. Duplicate comparison excludes only the import adapter's context hash, retaining immutable comparison of raw message content and remaining fields. Re-exported headers or unrelated new members can be retained without overwriting an already imported message.

Authoritative Pydantic definitions: `backend/app/schemas.py`. All modules import these objects. No shadow schemas.

## Python module seams
- `connectors.local.parse_messages(content: str, source_id: str, format: str = "json") -> list[StandardMessage]`; accept standardized objects and Feishu-export shape, preserve metadata. Validation errors must be explicit.
- Rendered CLI text retains literal numeric/boolean/null/array/quoted-string content rather than converting it to JSON scalar values. Only recognizable text envelopes are unwrapped; official body objects without valid text are rejected with safe field diagnostics. Raw metadata remains untouched; all-or-nothing import/dedupe unchanged.
- `agents.orchestrator.WorkflowOrchestrator(...).analyze(messages: list[StandardMessage], existing_projects: list[Project] | None = None) -> AnalysisResult`; synchronous. The orchestrator calls six bounded stages, invokes `workflow.builder.build_workflow`, returns verified proposal; no persistence. Default provider is local-demo; no network.
- `workflow.builder.build_workflow(facts: list[WorkFact], messages: list[StandardMessage], existing_projects: list[Project] | None = None) -> WorkflowUpdateProposal`. Resolves projects, builds nodes/relations and verifies literal evidence. Unassigned facts remain queryable; no invented project. Exported `verify_evidence(evidence, messages)` helper belongs to `workflow.verifier`.
- `retrieval.search.search_facts(query: str, facts: list[WorkFact], limit: int = 20) -> list[WorkFact]`.
- Main's repository persists and deduplicates immutable messages; analysis receives all messages for safe incremental rebuilding. Facts IDs must be deterministic from source/message and extracted content. Preserve existing review status only when fact content/evidence is unchanged. Graph IDs stable. All dates require timezone offsets.

## HTTP API (same origin, `/api` prefix)
- Import preflight: POST /api/import/preview?source_id=...&format=json|jsonl&naive_timezone=UTC%2B08:00|UTC with original file bytes -> ImportPreview {source_id,format_detected,total,valid,imported_candidates,duplicates,fingerprint,issues:[{position,line?,field,code,detail,raw}],messages:[StandardMessage],warnings}. Read-only; collects all row errors and DB/batch conflicts. Exact duplicates collapse to one message representative; valid is unique candidate count including existing identical messages, duplicates counts repeated original rows, imported_candidates counts new unique IDs. Same-ID conflicting input groups are wholly excluded, never arbitrarily choose the first. One bad record may have several diagnostics. raw issue data returns only to authenticated uploader for local download, never logs/detail. Fatal document errors use position0.
- POST /api/import/commit with the same original raw bytes/options plus fingerprint=<preview.fingerprint> re-preflights under repository lock and imports exactly the confirmed candidate set. Changed input/options or conflicting database data returns409 and requires recheck. No normalized JSON body expansion: files below byte cap do not fail merely because normalized metadata duplicates text. Empty candidate set400; fingerprint malformed/missing422. Preview writes nothing, needs no server token cache; fingerprint is a consistency hash, not authorization. With no issues the user's initial import action may commit automatically; any issues require explicit '仅导入可识别的N条' and raw issue download, not silent skips/invented IDs/times. Existing /api/import and strict /api/import/file remain atomic and unchanged. UTF8/BOM, UTF16/32 BOM decoding is deterministic; invalid encoding safe400, no lossy replacement. Config/file edits invalidate UI preview. Corrupt JSON cannot be guessed repaired, JSONL bad lines may coexist with valid rows. Auth/resource limits unchanged.

## 2026-11-09 source navigation additions
`GET /api/stats`, `/api/facts`, `/api/projects`, and `/api/projects/{id}/workflow` accept optional `source_id`. They filter the same persisted facts/graph (including historical workflow snapshots) without reprocessing, copying data or changing defaults. This is a navigation scope, not a multi-tenant permission boundary. Source IDs are query-encoded, including Unicode/slashes.

`GET /api/export` also accepts optional `source_id`, combined with `project_id`. JSON graph/facts and JSONL/training facts use the same source projection. Review/training gates remain unchanged.

`/api/projects/{id}/versions` filters snapshots containing facts from that source/project, and `/api/projects/{id}/memory` filters the same supported/non-rejected facts, when source_id is supplied.

`GET /api/sources/analysis?source_id=...` returns SourceAnalysis: messages, message_types, textual_messages, attachment_messages, reply_messages, extracted_messages, facts, assigned_facts, unassigned_facts, verified_facts, pending_review, projects, nodes, explicit_edges, attribution_methods, notes. Coverage/assignment counts do not establish accuracy. Attachment contents remain unread. Unknown source returns404.

Contextual local facts may include `attributes.project_attribution` with a method and source references. Header or reply attribution must be supported by literal EvidenceReference quotes; no attribution by temporal proximity alone. Raw messages and existing normalized outputs remain immutable.

Local contextual attribution uses `{method: explicit|section|catalog|reply|unassigned, support: EvidenceReference[], review_required:true}` (evidence alias also present). `reported_by:{id,name}` records the author separately from `assigned_actor_ids`, `assigned_actor_names`, `actor_role` and optional assignee aliases. Source names only resolve when observed mappings agree within the source. The primary evidence is always the actual observation; extra attribution references cannot introduce causal predicates.

`attributes.source_span={start,end}` uses Python Unicode code-point offsets into the immutable original message text, end exclusive. Facts/nodes preserve chronological order and these source offsets for tied timestamps. Offsets do not refer to HTML-decoded display text.

## Explicit source deletion
- `GET /api/sources/delete-preview?source_id=...` → SourceDeletionPreview `{source_id,messages,facts,projects_removed,reviews,versions,checkpoint,jobs_reset,version}`. Counts cover the source plus dependent facts; shared projects with retained facts survive. No mutation.
- `DELETE /api/sources?source_id=...` with DeleteSourceRequest `{confirmation:exact source_id,expected_messages:preview.messages,expected_version:preview.version}` → SourceDeletionResult `{source_id,messages_deleted,facts_deleted,projects_removed,reviews_deleted,versions_updated,jobs_reset,remaining_sources,version}`.
- Requires explicit typed confirmation in the UI. No selected source is deleted merely by adding this feature. Authentication applies. Changed message count/graph version or an active job yields409; missing source404; missing/wrong confirmation422/409. Impact counts describe the preview's read time.
- One transaction removes that source's stored messages/checkpoint, removes facts depending on its evidence and their reviews, redacts affected historical snapshots and removes empty snapshots/projects. Remaining facts rebuild the current graph deterministically; no LLM or Feishu call occurs. Shared projects and other-source raw messages/reviews remain intact.
- Global runtime/job result summaries are reset because they previously summarized the combined dataset; job IDs/status/timestamps are retained. Original files, private backups and Feishu data are outside this operation. This is local dataset removal, not a secure physical disk-erasure promise. Historical snapshot immutability has this explicit user-confirmed deletion exception.
