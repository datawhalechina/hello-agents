# 项目中文注释

## 输入与输出

- 输入：用户指定的完整项目根目录。根据提供的目录或项目文件定位根目录；仅在无法确定可访问项目时询问路径。
- 输出：无独立输出文件。直接修改输入项目中的源码注释，不生成项目副本、注释报告、术语词典或压缩包。
- 技能的“输出无”仅指没有新增交付文件；文件头的“输出文件”仍需如实描述程序生成的文件。
- 默认工作粒度：每个文件的五项文件头，以及每一个函数和方法的三项注释；不默认逐行解释函数体。
- 保持程序行为、数据、配置值和依赖不变，不借此修复、重构或执行项目。

## 确定完整项目范围

读取适用的 AGENTS.md，使用文件清单和项目结构确定全部自有源码，包括入口、模型、工具、测试、实验脚本、包初始化文件及适合添加注释的配置。完整项目不能擅自缩减为当前打开的文件或某个子目录。

跳过版本控制与 IDE 元数据、虚拟环境、安装依赖、缓存、二进制、数据集、训练权重及可确认的生成产物。目录名只是判断线索，不能据此漏掉实际维护的源码。项目随附并维护的第三方模型或算法实现仍需处理；保留其版权和许可声明。

先建立文件清单和函数清单。阅读实际实现，并按需追踪配置和调用方，确认各文件及函数用途、实际文件读写以及数据在内存中的传递方式。空白或未实现文件应明确标注占位状态，不编造功能。

## 五项文件头格式

保持以下字段名称和顺序，逐项换行。采用当前语言合法的注释语法；下面的 `#` 适用于 Python、R 等语言。

```text
# 代码用途：简洁说明文件负责的具体工作，并解释首次出现的专业术语。
# 输入文件：实际输入文件的绝对路径；没有文件输入则写“无”。
# 输入说明：说明各输入是数据集、配置、模型参数、标注表、图片等，以及用途。
# 输出文件：实际输出文件的绝对路径；没有文件输出则写“无”。
# 输出说明：说明输出是模型、预测表、特征、日志、图片等；无文件时说明内存返回值或终端显示内容。
```

已有文件头应更新或合并，避免重复叠加。文件头只保留这五项，不额外增加“术语说明”等字段；把必要释义融入代码用途、输入说明或输出说明。措辞简洁，按每个文件自身的实现编写，避免给整个目录复制同一套空泛说明。

## 每个函数的三项注释

对每个具名函数添加三项中文注释，包括类方法、构造函数、特殊方法、属性方法、回调、异步函数和嵌套函数。匿名函数应在能明确对应的相邻位置说明；不要为了添加注释重写表达式。没有函数的文件保留文件头即可。

Python 使用与文件头相同的 `#` 注释，放在函数定义之前，缩进与 `def` 一致。带装饰器时放在第一条装饰器之前，不拆开装饰器和定义；保留原有文档字符串。其他语言使用合法的原生注释语法。

```python
# 函数用途：融合前位、后位骨显像特征及临床信息，计算病例的分类分数。
# 输入说明：self：当前模型实例，由方法调用自动传入；x：按“批量、视角、颜色通道、高、宽”组织的前后位图像；clinical_info：各病例的性别、标准化年龄与病史三个数值。
# 输出说明：返回“批量大小×类别数”的分数张量，供训练损失或分类概率计算使用。
def forward(self, x, clinical_info):
    ...
```

- 三项名称固定为“函数用途、输入说明、输出说明”，按此顺序分别换行。多个参数可用分号分隔；参数较多时可在输入说明下用连续注释行逐项列出，仍属于同一个字段。
- 根据当前函数体、所属类和调用位置说明具体工作，不能仅把函数名翻译成中文，或对所有函数套用“处理数据”“执行相关操作”等空泛文字。
- 解释全部参数，包括位置参数、仅限关键字参数、可变位置参数、可变关键字参数，以及自动传入的 `self`、`cls`。写清每项承载什么数据、控制什么行为；能从实现确认时注明维度、单位、可选情况和关键默认值。不要臆造代码没有保证的类型或形状。
- `*args`、`**kwargs` 应说明参数实际传递给哪个操作；无参数时写“无”。自动传入的实例或类参数也应单独说明。
- 输出说明交代实际返回内容及用途。元组、字典、生成器应说明各分量、关键字段或逐次产出的内容；没有显式返回值时写“返回 None”，并说明文件保存、日志、绘图、参数更新等真实副作用。
- 构造函数说明初始化了什么状态；前向计算方法区分分数与概率；数据集取样方法说明返回的图像、临床信息、标签或病例名；训练和评估函数说明返回指标及更新状态。不得把所有 `forward`、`__init__` 或 `__call__` 机械套成同一句话。
- 原有文档字符串或普通注释可作为理解依据，但不得为了统一格式删除或改写运行时字符串。再次执行时更新已有三项注释，避免重复叠加。

文件头和函数注释的“输出说明”描述代码结果；技能本身仍不生成独立输出文件。

### 文件与路径的判断

- 根据实际读写调用、参数默认值、配置和调用链确定路径。区分当前入口会执行的操作、可选功能，以及已经被注释掉的代码；不能把被注释掉的保存操作写成实际输出。
- 保留代码中明确的 Windows、Linux 或网络绝对路径，不擅自迁移数据位置。相对路径结合工作目录、`__file__`、目录切换和入口约定解析，在相应说明中注明展开基准。
- 未知运行工作目录时，不默认把相对路径当成相对于源码目录。无法唯一确定绝对路径，应写“运行时确定（由某参数、配置项或调用方指定绝对路径）”，并说明参数来源；不得虚构一个固定路径来填满字段。
- 已知绝对根目录、未知文件名时，可使用带名称的占位符或匹配模式，例如 `{epoch}`、`{病例ID}`、`*.png`，并解释其含义。多个输入或输出用中文分号分隔，说明要能对应各项。
- 通过网络读取且没有固定本地路径时，保留资源地址，并说明本地缓存路径是否由外部库或配置决定。环境变量驱动的路径引用变量名，不把口令、令牌等值写入注释。
- 接收图像张量、数组、模型对象或已加载的权重字典，不等于读取文件；单纯返回对象、更新内存参数、打印结果或显示图形，不等于生成文件。此时路径栏写“无”，在说明栏交代真实接口。
- 说明真实副作用。下载缓存、按需保存及清理文件应标注触发条件；注释过程中不得运行这些功能。
- 路径栏保留可定位的路径或明确的动态来源；不要向路径、文件名或代码标识符内部插入术语释义。

## 专业术语解释

每个文件应能独立阅读：首次提到第三方模型、网络结构、算法、统计检验、指标或数据格式时，补充简短的中文含义和实际作用。适合时给出英文全称；仅展开缩写、仅翻译名称或增加另一个未解释的缩写都不足以说明概念。同一文件后续提及无需反复展开。

明确概念间的关系，例如 BiT 是迁移学习方案，ResNetV2 是其采用的网络结构。解释服务于当前文件的用途，不必展开算法推导或论文背景。数据格式应说明保存什么，指标应说明衡量什么，框架应说明提供什么功能。

依据当前实现解释完整术语，避免机械地按子串全局替换。例如，掩码采样权重控制抽样概率，不能解释成模型的可训练参数；自编码器同时包含编码和重建过程，不能只解释其中的“编码器”。同一缩写在不同领域可能含义不同，应先核对实现和引用。

优先查阅项目说明、引用论文及原始实现；有疑问时核对原论文或官方文档。无法确认的名称应说明其在本项目中的实际作用和不确定之处，不猜测英文全称、数据集规模或来源。

示例：一个定义 BiT 网络、通过内存接收数据的模块，可以这样写。

```python
# 代码用途：实现 BiT（Big Transfer，先在大规模数据上训练再迁移到新任务的方案）采用的 ResNetV2（Residual Network V2，第二版残差网络，用跨层相加保留信息，并在残差分支卷积前先调整特征尺度和进行非线性变换）图像分类模型。
# 输入文件：无（调用方传入内存数据）
# 输入说明：图像张量（多维数值数组）及已加载的预训练权重字典（在其他数据上学到的模型参数）。
# 输出文件：无（本文件不写入磁盘）
# 输出说明：返回模型实例或各类别的概率，加载权重时直接更新内存中的模型参数。
```

示例只用于说明写法。具体文件的内容和路径必须重新核对，不能照搬。

## 合法插入与验证

使用语言原生注释，例如 Python/R 的 `#`、JavaScript/Java/C++ 的 `//`、HTML/XML 的 `<!-- -->`、CSS 的 `/* */`、SQL 的 `--`。保留 shebang、编码声明、XML 声明、CSS 字符集声明、PHP 开标签、构建约束及版权声明的合法位置。使用注释而非可执行字符串，避免改变模块文档字符串或程序输出。

严格 JSON 等不允许注释的文件不应插入非法内容，也不应擅自改为另一种文件格式；在简短完成说明中交代这些例外。Notebook 只修改合适代码单元中的注释，保留现有执行结果和元数据，不执行单元。

尽量保留原编码、BOM、换行和排版。如必须调整编码才能合法写入中文，保持字符串含义及语言编码声明一致。不要重新格式化整个文件，也不要改动已有字符串、类型指令或工具控制注释。

修改前保存必要的比较基线，放在内存或系统临时目录，不在项目内生成备份或校验产物。修改后确认：

- 文件清单和函数清单覆盖完整；文件头五项、每个函数三项齐全，全部参数均已解释，没有重复注释。
- 用途与输入输出说明符合实现，固定路径有依据，动态路径明确来源，主要专业术语已有符合语境的释义。
- 差异仅涉及所需注释和必要的编码声明；原始代码、配置值及版权许可内容保持不变。
- 使用可用的语法解析或静态检查确认没有新增语法错误，区分项目原有问题。Python 可在内存中比较忽略位置属性的 AST 并调用 compile，避免产生 __pycache__；不导入或执行项目来验证注释。

Python 函数覆盖可运行本技能的 `scripts/check_function_comments.py <项目绝对路径>`：只读解析源码，检查三项顺序、重复字段和每个参数的说明，包括装饰器、嵌套函数、异步函数与可变参数。此脚本只检查注释格式和覆盖，不判断说明是否符合实现；匿名函数会单独计数，其他语言及语义准确性仍需人工核对。使用 `--exclude 目录名` 可补充排除已确认的外部依赖目录，不应据此排除项目自有代码。

默认不创建新测试、安装依赖或运行训练、推理、数据转换、清理等有副作用的入口。完成后只简短告知处理数量、必要的跳过项和验证结果，不生成独立交付文件；用户明确要求静默时省略完成说明。
