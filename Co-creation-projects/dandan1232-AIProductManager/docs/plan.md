## 验收重点

- 用户确认前不能生成分析；确认后的排除项与约束不会被覆盖。
- 修改需求会清空旧结果；失败重试不追加重复的用户回答。
- 搜索不可用时不产生虚构竞品，未知来源的条目不会进入报告。
- 文档将确认内容与 AI 建议分开；一致性冲突显式展示。
- 输入与模型输出以文本渲染；密钥不出现在公开 API 或项目记录。
- README 包括简介、功能、技术栈、安装配置运行、使用示例、限制与作者。
- 提供 main.ipynb，Notebook 调用真实工作流，提交时无运行输出或密钥。
- 提交文件小于 5 MB；依赖环境、数据库、运行结果、截图不进入 Git。
