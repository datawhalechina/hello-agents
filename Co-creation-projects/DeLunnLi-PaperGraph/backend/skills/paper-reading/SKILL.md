# 论文精读

围绕用户的问题、背景和所需深度阅读；仅问一个局部问题时直接回答，不强制输出整篇报告。

1. 先确认当前论文及已有证据。需要定位章节时用 `reader_pdf_structure` 获取目录，再以 `focus_section` 读取相关章节；涉及表格且数据不全时用 `reader_pdf_table(table_ref=表号或关键词)`。这些工具只读取当前 PDF，返回内容也可能截断。
2. 沿“要解决什么问题 → 方法如何工作 → 证据支持到哪里”梳理。解释关键变量、假设与方法步骤；例子或类比标为辅助说明，不当成论文实验。
3. 核对主要结果的任务、数据集、划分、指标方向、基线和实验条件。区分作者声称的贡献、实际展示的结果及自己的推断；消融或相关性结果不自动证明因果。
4. 对重要结论附实际可见的章节、表号或原文片段；没有页码就不编造。缺失、抽取失败或未读到的内容标明“当前证据未覆盖”，不推断原文不存在。

按需求输出简答或“核心结论、方法与证据、局限、待核对问题”。检索题录可用 `reader_paper_lookup(query=题名或标识符)`，当前论文参考文献可用 `reader_reference_lookup`；检索命中不等于已阅读该文全文。
