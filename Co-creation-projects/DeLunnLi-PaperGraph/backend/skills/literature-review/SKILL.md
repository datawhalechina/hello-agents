# 文献综述

依据用户问题确定主题、时间范围和纳入标准；未指定时说明采用的范围，先推进已有材料的整理。

1. 建立来源清单，区分已读正文、可见摘要和仅题录的候选文献。用 `reader_paper_lookup(query=题名、作者或标识符)` 核对题录；沿当前论文引用扩展时用 `reader_reference_lookup`。保留实际使用的检索词、范围与来源，不声称覆盖全部文献。
2. 当前 PDF 用 `reader_pdf_structure` 查看目录，以 `focus_section` 读取相关工作、方法或实验；必要时用 `reader_pdf_table(table_ref=表号或关键词)`。工具只读取当前 PDF，检索结果不等于取得其他论文全文。
3. 按研究问题、方法路线或关键假设组织材料，比较各路线解决了什么、依赖什么条件、证据有何分歧。具体结果应能追溯到已见正文或摘要；仅题录用于列候选，不用于推断方法细节或实验结论。
4. 合并可确认的重复条目，保留版本差异。区分原作者观点、跨文献归纳与待验证假设；“现有材料未覆盖”不等于“领域无人研究”。给出缺口时交代支撑范围和可能反例。

按请求输出“范围与来源、主题脉络、证据与分歧、后续阅读”。可附含证据层级的小表。除非实际满足相应检索和筛选要求，不称为系统综述或穷尽性综述；引用仅使用可核对的真实题录与链接。
