# 论文对比

先明确用户要比较的论文及决策维度。为每篇标注证据范围：可见正文、用户摘录、摘要或仅题录；题名相似不能视为同一论文。

1. 当前 PDF 可用 `reader_pdf_structure` 定位章节并通过 `focus_section` 补读，用 `reader_pdf_table(table_ref=表号或关键词)` 核对表格。工具不能切换到任意论文全文；其他论文只能使用已有材料。缺少一方证据时先给可支持的局部比较，并指出需要补充哪段材料。
2. 以一致维度比较研究问题、输入输出、关键假设、方法差异、计算资源和局限。每个结论注明论文及可见章节或表号，区分作者报告、自己的推断和未知项。
3. 数值比较前对齐数据集版本、划分、评价协议、指标方向、训练数据及资源预算。条件不一致时并列报告并解释差异，不据此排出公平优劣；只对可比数值计算差值，区分百分点和相对百分比。
4. 选型建议绑定用户场景及证据，指出哪些条件变化会改变建议。没有足够证据时不强行选赢家。

可输出“共同问题、差异表、可比结果、适用场景与缺口”，长度按请求调整。`reader_paper_lookup(query=题名或标识符)` 和 `reader_reference_lookup` 仅辅助核对题录或发现文献，不提供多篇全文证据。
