# 复现准备检查

先界定要复现的具体结果，以及用户关注的资源与精度要求；证据不足时先形成可执行的核对清单。

1. 用 `reader_pdf_structure` 定位当前 PDF 的方法、实验和附录，再以 `focus_section` 补读；用 `reader_pdf_table(table_ref=表号或关键词)` 核对目标结果。工具仅访问当前 PDF；未获取的附录、代码或数据不能视为已检查。
2. 提取数据集版本与许可说明、预处理、划分、泄漏防范、基线实现、模型和依赖版本、超参数、随机种子、硬件、训练预算、指标定义、重复次数与误差范围。只检查与目标实验相关的项目。
3. 对每项标注“原文明确报告、信息不完整、当前材料未见”，附可见章节或表号。作者声称开源不等于已验证链接可用或代码可运行；自己的推断和建议单列。缺失协议只说明复现风险，不直接断言结果无法复现。
4. 提出最小复现顺序：准备数据与环境、核对基线、运行目标设置、按相同协议比较、记录偏差。区分论文要求与建议的补充实验；没有依据时不编造命令、配置、成本或容差。

按需求给出“目标结果、已知配置、关键缺口、复现计划”。`reader_paper_lookup(query=题名或标识符)` 或 `reader_reference_lookup` 可核对引用基线题录，但不能据此补齐其全文或实现细节。未实际运行时明确结论只是文献层面的复现准备评估。
