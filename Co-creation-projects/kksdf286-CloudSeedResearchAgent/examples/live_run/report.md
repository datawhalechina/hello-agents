# 多源观测缺失/延迟下的作业条件识别与拒判原型

> 待验证候选假设；新颖性尚未系统检索核验。

## 一句话研究问题

在导师确认的地区与云型下，当静止卫星与地基雷达观测存在缺失或延迟时，能否用可解释的多源融合模型识别作业条件，并在证据不足时输出拒判？

## 可证伪假设

在事件/时间独立划分下，引入观测完整性与时效性特征的多源融合模型，其作业条件识别指标优于仅用单源观测的模型，且拒判机制能在证据不足样本上降低错误判定率。

## 数据、基线与评测协议

数据要求：先做数据盘点：确认导师指定地区与云型的卫星、雷达、探空等可获取观测及其时间分辨率、缺失与延迟记录方式；尚无经专家独立标注的作业条件标签，需先制定标注手册（依据适用标准与决策时刻观测，由专家独立确认），并做小样本双人标注一致性验证；需明确数据使用许可与脱敏要求。

基线：
- 单源模型：仅用静止卫星红外指标特征
- 单源模型：仅用地基雷达回波特征
- 简单多源模型：卫星与雷达特征直接拼接的常规分类器

评价指标：
- 作业条件识别：事件级精确率、召回率与F1
- 拒判性能：拒判率与错误判定率（在证据不足子集上）
- 校准：概率校准误差（如Brier分数或可靠性曲线）
- 标注一致性：专家双人标注的Kappa或一致率

## 最小可行实验

1. 数据盘点与标注验证：整理候选事件清单，抽取小样本由专家独立标注作业条件，计算标注一致性，未达标则修订手册后重标。
2. 特征与缺失机制设计：构造观测完整性、时效性、延迟量等元特征，明确缺失与延迟的模拟或真实记录方式。
3. 建模与验证：在事件/时间独立划分下训练单源、简单多源与融合模型，阈值仅在验证集选择，测试集不参与调参。
4. 拒判评估：在测试集上按验证集选定阈值评估拒判行为，并做随机判定合理性检查（仅作合理性检查，不作强基线）。

## 停止条件与反证

若在事件/时间独立测试集上，融合模型的作业条件识别F1不优于任一单源模型，或拒判机制未能在证据不足子集上降低错误判定率，则不支持本假设。

## 风险与替代解释

- 尚无经专家独立标注的数据，标注成本与一致性可能不达标
- 地区与云型待导师确认，可能超出S1适用范围
- 观测缺失与延迟的真实记录可能不足，需依赖模拟，外部效度受限

# 历史作业记录与专家条件标签的语义差异及辅助标注可行性

> 待验证候选假设；新颖性尚未系统检索核验。

## 一句话研究问题

在导师确认的地区与云型下，历史人工增雨作业记录（是否实施作业）与专家独立确认的作业条件标签之间存在多大语义差异，前者能否作为辅助标注信号而非直接标签？

## 可证伪假设

历史作业记录与专家作业条件标签在事件级上一致性有限；将历史记录作为辅助特征或弱标签使用时，其增益低于直接使用专家标签，且不能替代专家标签。

## 数据、基线与评测协议

数据要求：先做数据盘点：确认可获取的历史作业记录字段（项目、年份、地区、催化剂、设备、目的、目标与对照区域、日期等）及其许可；同时按T1方式建立小样本专家独立标注的作业条件标签；需核对本地地区与云型是否处于适用标准范围。

基线：
- 仅用专家标签训练的监督模型
- 仅用历史作业记录作为标签训练的模型
- 历史记录作为辅助特征与专家标签联合训练的模型

评价指标：
- 语义差异：历史记录标签与专家条件标签的事件级一致率与Kappa
- 识别性能：事件级精确率、召回率与F1
- 辅助增益：联合方案相对仅专家标签方案的F1变化
- 标注成本：单位事件专家标注耗时（用于评估可行性）

## 最小可行实验

1. 语义对齐：将历史作业记录字段与专家标注手册逐项对照，明确“实施作业”与“具备作业条件”的语义差异。
2. 小样本标注：对同一事件集分别获取历史记录标签与专家条件标签，计算两者事件级一致性。
3. 建模对照：在事件/时间独立划分下，比较仅专家标签、仅历史记录标签、联合使用三种方案的识别指标，阈值仅在验证集选择。
4. 辅助标注评估：检验历史记录作为辅助特征或弱标签时是否带来增益，并做随机判定合理性检查（仅作合理性检查，不作强基线）。

## 停止条件与反证

若历史作业记录与专家条件标签的事件级一致性高到可互换，或历史记录作为辅助特征带来的F1增益不低于直接使用专家标签，则不支持本假设。

## 风险与替代解释

- 历史记录可能覆盖地区与云型有限，与本地适用标准范围不匹配
- 专家标注资源有限，小样本一致性可能不稳定
- 历史记录字段抽取质量依赖原始报告，未报告本地可用性
