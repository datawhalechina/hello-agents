# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User delegated: Python backend, standard-library local web server, HTML/CSS/JavaScript interface, and a CLI. No frontend build or dependency installation is needed.

## Users
The owner is a meteorology/deep-learning graduate researcher using an existing Obsidian research vault, and a HelloAgents learner preparing a runnable GitHub assignment this afternoon.

## Product Purpose
Compare literature relevant to identifying cloud-seeding conditions, then draft evidence-linked research questions and falsifiable minimum experiments.

## Operating Context
Local Windows desktop; configured DeepSeek endpoint; existing paper notes, literature matrix and research-topic templates. Research subject: cloud-seeding condition identification. User approved a directly usable local browser demonstration plus CLI.

## Capabilities and Constraints
Real model analysis with HelloAgents, four explicit roles, source and evidence identifiers, source ingestion, two candidate hypotheses, critique, Markdown/BibTeX and additive Obsidian export. Offline fixture is visibly labelled and cannot analyse changed inputs. No verified local meteorological dataset or expert labels are supplied. No operational seeding recommendations.

## Evidence on Hand
Three independently checked scholarly records and one scoped meteorological standard. Bundled material consists of short human paraphrases with provenance, not full-paper extraction. Existing vault has reusable source/topic structures.

## Product Principles
- Every factual claim retains source identifiers and reading scope.
- Task and metric comparability precedes numerical rankings.
- Ideas remain hypotheses until literature and experimental validation.
- Make the first run and export obvious; complete a working small assignment today.
