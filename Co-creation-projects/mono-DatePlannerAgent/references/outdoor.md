# outdoor · 公园 / 江边 / 夜景专项调研

## 必查字段

- 当天天气（`maps_weather`：降雨、温度）
- 日落时间（网页搜索确认，用于夜景安排）
- 开放时间
- 夜间交通（散场后能否打到车/公交是否还有）
- 步行距离
- 下雨时的室内备用方案

## 工具调用顺序

1. 高德天气：`maps_weather(city)` 确认当天天气。
2. 高德搜索：`maps_text_search("公园", city)` / `maps_text_search("湿地公园", city)` 找候选。
3. 高德详情：`maps_search_detail` 拿地址、开放时间。
4. 网页搜索：查日落时间、音乐喷泉等动态演出时间（如有）。
5. 高德距离：`maps_distance` 算公园到前一个节点的通勤时间。

## 数据源优先级

- 天气/日落/动态演出时间：网页或官方 > 无（写“需要确认”）。
- 公园位置/开放时间：高德 MCP。

## 筛选规则

- 户外节点放在行程末尾（晚上凉快后），作为可选续场。
- 优先离家近的公园；太远（跨片区）的夜景要提醒用户权衡。
- 下雨必须给室内备用方案。

## 失败兜底

- 天气恶劣 → 直接切室内方案。
- 公园搜不到 → 换关键词（广场 / 湖 / 湿地 / 绿道）。
- 动态喷泉等时间未知 → 写“以现场为准”。
