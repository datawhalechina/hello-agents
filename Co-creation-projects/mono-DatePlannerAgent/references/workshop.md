# workshop · 手工体验专项调研

## 必查字段

- 体验项目（陶艺 / 绘画 / 银饰 / 烘焙 / DIY 等）
- 可预约时段
- 体验时长
- 两人价格
- 是否需要预约、是否可现场排队
- 具体门店位置
- 附近餐饮和续场地点

## 工具调用顺序

1. 高德关键词搜索：`maps_text_search("陶艺", city)` 等，多换关键词（手工 DIY / 陶艺 / 银饰 / 烘焙）。
2. 高德详情：`maps_search_detail` 拿地址、电话、营业时间、人均（如有）。
3. 电话或网页核实：预约规则、可预约时段、两人价格。
4. 高德距离：`maps_distance` 算手工店到午餐/续场点的通勤时间。

## 数据源优先级

- 价格/预约时段：门店电话或网页 > 高德 biz_ext > 无（写“需要确认”）。
- 门店位置与营业时间：高德 MCP。

## 筛选规则

- 优先两人可同时参与的体验项目。
- 体验时长要能插入行程时间轴，别和正餐/夜景冲突。
- 门店在商场内且用户避开商场时，优先独立门店或公寓楼工作室，并说明。

## 失败兜底

- 某类手工搜不到 → 换关键词（陶艺→手工DIY→银饰→烘焙）。
- 无价格/预约信息 → 电话确认或写“需要确认”。
