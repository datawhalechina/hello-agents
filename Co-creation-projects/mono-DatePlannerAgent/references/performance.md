# performance · 演出 / Livehouse 专项调研

## 必查字段

- 当天是否有演出
- 开始和结束时间
- 票价
- 是否还有余票
- 场馆位置
- 散场交通
- 附近夜宵或续场地点

## 工具调用顺序

1. 网页搜索/浏览器：查当天演出（大麦、秀动、猫眼等票务平台，或场馆官方账号）。
2. 高德搜索：`maps_text_search(场馆名, city)` 确认场馆位置。
3. 高德详情：`maps_search_detail` 拿地址、电话。
4. 高德距离：`maps_distance` 算场馆到晚餐/续场点的通勤时间。

## 数据源优先级

- 演出时间/票价/余票：票务平台或场馆官方 > 无（写“需要确认”）。
- 场馆位置：高德 MCP。

## 筛选规则

- 演出时间（尤其散场时间）是固定锚点，安排前后餐饮与续场要围绕它。
- 散场后交通要预留时间，太晚的活动需确认夜宵地点和回家交通。
- 预算内优先中等价位档；余票紧张提示提前购票。

## 失败兜底

- 当天无演出/已售罄 → 换日期或换活动方向（电影/展览/手工）。
- 票务信息查不到 → 电话场馆确认或写“需要确认”。
