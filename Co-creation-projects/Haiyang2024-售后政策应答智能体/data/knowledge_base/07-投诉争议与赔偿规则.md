# 投诉争议与赔偿规则

> 业务域：投诉与赔偿 ｜ 规则前缀：`CMP` ｜ 责任部门：客户服务中心 / 合规与法务部
> 覆盖场景：投诉分级、赔偿审批、平台介入与监管投诉
> **重要**：本域全部规则**仅可人工执行**，智能体与客服均无赔偿决定权

---

## CMP-001 投诉分级与响应规则

| 规则编号 | CMP-001 |
| 适用场景 | 用户表达不满、要求投诉、要求解释 |
| 责任部门 | 客户服务中心 |
| 时效标准 | 受理确认 2 小时内；处理反馈 3 个工作日 |
| 关联规则 | GEN-004、TAL-002 |

### 投诉分级

| 等级 | 判定信号 | 响应要求 |
|---|---|---|
| **一级（一般不满）** | 表达不满意，但无升级诉求 | 客服直接处理，致歉 + 解决方案 |
| **二级（明确投诉）** | "我要投诉""找你们领导""给我个说法" | 记录投诉，2 小时内受理确认，转投诉专员 |
| **三级（激烈投诉）** | 涉及赔偿诉求、威胁曝光、多次投诉未解决 | 立即升级至客服主管，专人跟进 |
| **四级（重大风险）** | 提及法律途径、监管投诉、媒体曝光、人身安全 | **立即升级至合规与法务部**，同步上报 |

### 判定要点

| 信号 | 归入等级 |
|---|---|
| "这个体验太差了" | 一级 |
| "我要投诉你们" | 二级 |
| "已经第三次找你们了" | 三级 |
| "必须赔我 1000 元" | 三级（涉及赔偿） |
| "我要走法律途径""投诉到消协" | 四级 |
| "我要发到网上曝光" | 四级 |
| 涉及人身伤害、食品安全事故 | 四级 |

### 处理流程

1. **先安抚，不辩解**——不与用户争论对错
2. 判定投诉等级
3. 一级：直接给出解决方案
4. 二级及以上：
   - 完整记录投诉内容、时间、诉求
   - 告知受理时效与跟进方式
   - 转对应层级处理
5. 四级：**立即升级**，同时提示用户已进入专人处理流程

### 禁止承诺

- ❌ 不可承诺"一定给您满意的答复"
- ❌ 不可承诺赔偿金额
- ❌ 不可承诺处理结果
- ❌ 不可与用户争论责任归属
- ❌ 不可自行判定是否属平台责任

### 需补充信息

订单号、投诉事项、发生时间、诉求内容、是否已反馈过。

## CMP-002 赔偿权限与审批规则

| 规则编号 | CMP-002 |
| 适用场景 | 用户提出赔偿、补偿、赔付诉求 |
| 责任部门 | 客户服务中心 + 合规与法务部 |
| 时效标准 | 依审批层级而定；一般 3–5 个工作日 |
| 关联规则 | GEN-004、CMP-001、LOG-001 |

### 赔偿权限矩阵

| 金额区间 | 审批层级 | 说明 |
|---|---|---|
| 0 元 | 智能体 / 客服 | **仅可致歉，无任何赔偿承诺权** |
| ≤ 200 元 | 客服主管 | 如运费补偿、小额优惠券 |
| ≤ 1000 元 | 客服经理 + 财务 | 需说明事由与依据 |
| ≤ 5000 元 | 客服总监 + 合规 | 需书面说明 |
| > 5000 元 | 总经理审批 | — |
| 法定赔付 | 合规与法务部 | 依《消费者权益保护法》等执行 |

> **核心原则**：**智能体与一线客服对任何金额均无承诺权**。所有赔偿诉求一律转人工。

### 常见赔偿类型

| 类型 | 说明 | 依据 |
|---|---|---|
| 超时发货赔付 | 依平台规则 | 平台服务协议 |
| 运费补偿 | 质量问题退换时 | LOG-005 |
| 商品损失赔付 | 丢件、损坏 | LOG-002 / LOG-003 |
| 法定惩罚性赔偿 | 欺诈、虚假宣传等 | 《消费者权益保护法》相关规定 |
| 人身损害赔偿 | 商品造成人身伤害 | 法律规定 |

### 处理流程

1. **接收诉求，不做评价**，完整记录
2. 明确告知"赔偿需专人审批，我们会在 X 个工作日内反馈"
3. 转人工并附完整信息（订单、诉求、证据、沟通记录）
4. **智能体不参与任何金额讨论**

### 禁止承诺（最重要的一组）

- ❌ **绝对不可承诺任何赔偿金额**
- ❌ 不可使用"至少""最多""大概能赔 X 元"等表述
- ❌ 不可暗示"应该能赔"
- ❌ 不可与用户讨价还价
- ❌ 不可承诺审批通过率
- ❌ 不可承诺一定会有人联系（应说"会在 X 个工作日内反馈"）

### 需补充信息

订单号、诉求金额、事由说明、相关证据、紧急程度。

## CMP-003 平台介入与监管投诉规则

| 规则编号 | CMP-003 |
| 适用场景 | 用户申请平台介入、向监管部门投诉、法律途径解决 |
| 责任部门 | 合规与法务部 |
| 时效标准 | 立即升级，24 小时内响应 |
| 关联规则 | CMP-001、CMP-002 |

### 判定标准

| 情形 | 处理 |
|---|---|
| 用户表示要向消协 / 12315 投诉 | **四级投诉**，立即升级合规与法务部 |
| 用户表示要起诉 | 同上，**不得劝阻** |
| 用户申请平台介入商家纠纷 | 转入平台介入流程 |
| 用户已向监管部门投诉并收到反馈 | 立即升级，提供完整材料 |
| 用户提及媒体曝光 | 立即升级并上报 |

### 处理原则

| 原则 | 说明 |
|---|---|
| **不阻止** | 不得劝阻用户行使合法维权权利 |
| **不承诺** | 不得承诺监管处理结果 |
| **留痕** | 完整记录诉求与处理过程 |
| **上报** | 立即升级，不自行处理 |
| **配合** | 配合提供所需的交易与沟通记录 |

### 沟通话术要点

- 表达重视："您反馈的情况我们非常重视"
- 说明流程："已为您升级至专人处理，会在 24 小时内与您联系"
- **不劝阻**："您有权通过任何合法途径维护自身权益"

### 禁止承诺

- ❌ 不可劝阻用户投诉或起诉
- ❌ 不可承诺监管部门的处理结果
- ❌ 不可承诺"私下和解"
- ❌ 不可自行解释法律条款
- ❌ 不可承诺"一定会给您满意的结果"

### 需补充信息

订单号、投诉对象、诉求内容、已采取的维权动作。

## 特别说明

> **本域规则的执行主体限制**
>
> `CMP` 域全部规则**不接受自动处理**。智能体在此域的唯一职责是：
> 1. **识别**用户诉求属于投诉或赔偿范畴
> 2. **安抚**情绪，不做责任评价
> 3. **完整记录**诉求与证据
> 4. **立即转人工**，并告知用户后续跟进方式
>
> 任何自动化系统**不得**在此域作出结果性判断或金额承诺。
