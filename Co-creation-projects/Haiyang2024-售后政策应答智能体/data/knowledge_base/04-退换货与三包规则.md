# 退换货与三包规则

> 业务域：退换货与三包 ｜ 规则前缀：`RET` ｜ 责任部门：售后服务中心
> 覆盖场景：无理由退货、质量问题、少件漏发、三包维修、换货、除外品类
> 通用要求：质量与少件类问题**必须有证据材料**方可进入审核

---

## RET-001 七天无理由退货

| 规则编号 | RET-001 |
| 适用场景 | 用户因个人原因（不喜欢、尺码不合适、买错）要求退货 |
| 责任部门 | 售后服务中心 |
| 时效标准 | 签收日起 7 个自然日内提出；审核 1–3 个工作日 |
| 依据 | 《消费者权益保护法》第二十五条（网络购物七日无理由退货） |
| 关联规则 | RET-006、LOG-005、PAY-001 |

### 判定标准

同时满足以下全部条件方可适用：

| 条件 | 要求 |
|---|---|
| 时间 | 自签收日起 7 个自然日内 |
| 商品状态 | 完好、未经使用、吊牌及包装完整 |
| 配件 | 配件、赠品、说明书齐全 |
| 品类 | 不属于 [RET-006](04-退换货与三包规则.md#ret-006-不适用无理由退货的品类) 的除外品类 |

> **签收日起算**：以物流系统记录的签收时间为准；无签收记录的，以物流妥投时间为准。

### 处理流程

1. 核对签收日期，确认是否在 7 日内
2. 确认商品品类是否适用无理由退货
3. 说明退货条件与操作流程，引导用户在订单页提交申请
4. 说明运费承担规则（非质量问题的退货运费由用户承担，见 LOG-005）
5. 告知审核时效与后续流程
6. 存在商品状态争议的，需用户提供商品现状照片

### 客户沟通要点

- 说明法定权利，不设置额外门槛
- 明确告知不适用无理由退货的品类及原因
- 说明"商品完好"的判定标准，避免后续争议

### 禁止承诺

- ❌ 不可承诺"申请一定通过"
- ❌ 不可承诺"一定全额退款"
- ❌ 不可承诺运费一定由平台承担
- ❌ 不可承诺退款到账的具体日期（应转述 PAY-001 的时效区间）

### 需补充信息

订单号、签收时间、申请退货原因、商品现状照片（如有争议）。

## RET-002 质量问题退换处理

| 规则编号 | RET-002 |
| 适用场景 | 商品破损、无法正常使用、与描述不符、功能故障 |
| 责任部门 | 售后服务中心 |
| 时效标准 | 审核 1–2 个工作日 |
| 依据 | 《消费者权益保护法》第二十四条、《产品质量法》相关规定 |
| 关联规则 | RET-004、LOG-005、CMP-002 |

### 判定标准

| 情形 | 判定要点 |
|---|---|
| 外观破损 | 需照片清晰体现破损部位与程度 |
| 功能故障 | 需视频或说明体现故障现象 |
| 与描述不符 | 需对比商品页描述与实际商品 |
| 疑似使用不当导致 | 需质检判定，**不得由客服或智能体预判** |

### 处理流程

1. 引导用户提供证据材料（照片 / 视频，需能清晰体现问题）
2. 材料齐备后提交质检审核
3. 审核结果：

| 结果 | 处理 |
|---|---|
| 确认为质量问题 | 提供换货或退货退款方案，运费由平台承担 |
| 判定为用户原因 | 说明判定依据，按 RET-001 或维修处理 |
| 需进一步检测 | 告知寄回检测流程与时效 |

4. 审核完成前**不作出结论性表态**

### 客户沟通要点

- 首句致歉，表达重视
- 明确说明所需材料与提交方式
- 说明审核时效与结果通知方式
- 涉及人身安全的（如漏电、异味），**立即提示停止使用**

### 禁止承诺

- ❌ **不可在审核前承诺"一定退款"或"一定换新"**
- ❌ 不可替质检环节作出结论
- ❌ 不可承诺审核时间一定在 1 天内
- ❌ 不可承诺赔偿金额（涉及赔偿需转 CMP-002）

### 需补充信息

订单号、问题照片或视频、问题描述、是否已尝试使用、是否存在人身安全隐患。

## RET-003 少件漏发处理

| 规则编号 | RET-003 |
| 适用场景 | 收到商品缺少配件、套装少件、赠品未发 |
| 责任部门 | 售后服务中心 |
| 时效标准 | 核实 1–2 个工作日；补发按 LOG-001 计时 |
| 关联规则 | RET-002、LOG-001、PAY-003 |

### 判定标准

| 情形 | 判定要点 |
|---|---|
| 商品数量与订单明细不符 | 需核对订单明细 |
| 配件缺失 | 需对照商品页的配件清单 |
| 赠品未发 | 需核对活动规则与订单记录 |
| 用户主张少件但无凭证 | 需引导提供开箱记录或包裹面单 |

### 处理流程

1. 引导用户提供**包裹面单照片**与**缺件清单**
2. 核对订单明细中的商品与配件组成
3. 确认为漏发的，确认用户处理意愿：

| 用户意愿 | 处理方式 |
|---|---|
| 补发 | 按 LOG-001 重新计算发货时效 |
| 部分退款 | 按 PAY-003 核算差额 |

4. 核对后确认未漏发的，说明订单构成并致歉沟通

### 禁止承诺

- ❌ 核实前不可承诺"马上补发"
- ❌ 不可承诺补发的具体到达时间
- ❌ 未核对订单明细前不可确认"确实漏发"
- ❌ 不可承诺额外补偿

### 需补充信息

订单号、包裹面单照片、缺少的配件清单、期望处理方式（补发 / 部分退款）。

## RET-004 三包期内维修

| 规则编号 | RET-004 |
| 适用场景 | 商品在保修期内出现性能故障，用户要求维修 |
| 责任部门 | 售后服务中心 |
| 时效标准 | 受理 1–2 个工作日；维修周期视品牌与故障而定 |
| 依据 | 《部分商品修理更换退货责任规定》 |
| 关联规则 | RET-002、RET-005 |

### 三包时限说明

三包期限依据商品目录与品牌规定，常见参考：

| 品类 | 参考三包期 |
|---|---|
| 家用电器 | 整机 1 年，主要部件 1–3 年（依目录） |
| 移动电话 | 主机 1 年 |
| 计算机 | 整机 1 年，主要部件 2 年 |
| 其他 | 以商品页与保修卡标注为准 |

> **以商品页与保修卡标注为准**，不得自行推定。

### 处理流程

1. 确认商品在保修期内（核对购买时间与保修期）
2. 确认故障属性能故障（非人为损坏）
3. 提供维修渠道：
   - 品牌官方售后网点
   - 平台合作维修点
   - 寄修服务
4. 告知维修流程、预计周期与寄送方式
5. 维修完成后回访确认

### 三包的顺位规则

| 情形 | 处理顺序 |
|---|---|
| 7 日内出现性能故障 | 可选择退货、换货或修理 |
| 8–15 日内出现性能故障 | 可选择换货或修理 |
| 超过 15 日 | 通常为修理；符合换货条件的可换货 |

> 具体适用需结合品类目录与品牌规则，**存在争议时转人工判定**。

### 禁止承诺

- ❌ 不可承诺"一定能修好"
- ❌ 不可承诺维修周期
- ❌ 不可承诺一定免费维修（需先判定是否人为损坏）
- ❌ 不可自行判定是否属三包范围

### 需补充信息

订单号、购买时间、故障描述、是否在保修期内、是否有保修卡或发票。

## RET-005 换货流程与时效

| 规则编号 | RET-005 |
| 适用场景 | 用户要求换货（换同款或换其他规格） |
| 责任部门 | 售后服务中心 |
| 时效标准 | 审核 1–3 个工作日；换出商品按 LOG-001 计时 |
| 关联规则 | RET-001、RET-002、LOG-005 |

### 判定标准

| 情形 | 是否可换货 | 运费 |
|---|---|---|
| 质量问题 | 可换 | 平台承担 |
| 少件漏发 | 可补发或换 | 平台承担 |
| 七天无理由期内换货 | 可换（视库存） | 通常用户承担 |
| 无库存 | 改为退货退款 | 按对应规则 |
| 超出无理由期限且非质量问题 | 通常不可换 | — |

### 处理流程

1. 确认换货原因与责任归属
2. 核查目标商品库存
3. 库存充足：说明换货流程、寄回要求与寄出时效
4. 无库存：说明情况并给出替代方案（退货退款 / 等待补货）
5. 说明运费承担方
6. 告知换出商品的发货时效

### 禁止承诺

- ❌ 不可承诺"一定能换到"
- ❌ 不可承诺换出商品的具体发货时间
- ❌ 不可承诺运费一定由平台承担
- ❌ 不可承诺升级为更高规格商品

### 需补充信息

订单号、换货原因、目标规格、是否接受替代方案。

## RET-006 不适用无理由退货的品类

| 规则编号 | RET-006 |
| 适用场景 | 判断某商品是否适用七天无理由退货 |
| 责任部门 | 售后服务中心 + 品类运营部 |
| 依据 | 《消费者权益保护法》第二十五条第二款 |
| 关联规则 | RET-001、SPC-001 ~ SPC-004 |

### 法定不适用品类

| 品类 | 说明 |
|---|---|
| 消费者定作的商品 | 定制类，如刻字、定制尺寸 |
| 鲜活易腐商品 | 生鲜、鲜花、短保食品 |
| 在线下载或已拆封的数字化商品 | 软件、音像制品、电子书 |
| 交付的报纸、期刊 | — |
| 其他根据商品性质不宜退货并经购买时确认的 | 需在购买页面明确提示并经用户确认 |

### 平台约定不适用品类（需页面明示）

| 品类 | 原因 |
|---|---|
| 已拆封的贴身用品 | 卫生要求 |
| 已激活的数码产品 | 影响二次销售，激活信息不可逆 |
| 已拆封的食品、保健品 | 食品安全 |
| 明确标注"不支持无理由退货"的商品 | 需在商品页显著位置提示 |
| 虚拟商品、充值类 | 已交付即消耗 |

### 处理要点

1. 判定前**必须核对商品页是否有明确提示**
2. 若商品页未提示，**不得直接以品类为由拒绝**
3. 用户对"是否支持无理由"有争议的，转人工判定
4. 不适用无理由退货**不等于不适用质量问题退换**——质量问题仍按 RET-002 处理

### 客户沟通要点

- 说明具体依据（法定 / 平台约定）
- 不适用无理由的商品，仍需说明质量问题的处理路径
- 态度平实，避免让用户感觉被推诿

### 禁止承诺

- ❌ 不可自行扩大解释不适用品类
- ❌ 不可对商品页有明确提示的商品仍承诺可无理由退货

### 需补充信息

订单号、商品品类、购买页面是否有相关提示。
