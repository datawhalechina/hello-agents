# requirements — NTU 选课助手

> 正本只写拍板后的结论；过程拆解在 `01-需求拆解.md`。

## Must（MVP 范围）

1. 课程信息问答：基于官方数据（WIS 本科目录 / NTU 官网 CCA 项目页 / WIS 课表），回答可溯源（附 source_url）
2. 反幻觉三板斧：只依据工具返回作答、查不到明说、输出附来源
3. 检索层：课程卡片 + BM25/向量混合检索（RRF 融合）
4. Agent 层：ReAct 单 Agent 端到端问答（D2）→ 规划/检索/审查三 Agent 协作 + Reflection ≤3 轮（D3）
5. 校验工具（D3）：课表时间冲突检测（仅有课表数据的课）、专选门数 ≥4、AU 上限（Option1 通选 ≤18AU）、先修/互斥提示
6. 评估：15 条检索金标 + 20 条端到端真实跑分（准确率 + 响应时间），数字与简历口径分开记录、不造假
7. 数据边界如实告知：研究生课表官方不公开 → 冲突检测仅覆盖有课表数据的课程

## Should / Could / Won't

- **Should**：中英混合查询；MCP 接入演示；课表数据覆盖 CSC 本科
- **Could**：云端/本地 embedding 效果对比；扩展更多本科专业分类；扩展其他 MSc 研究生项目课程（逐项目页抓取，2026-10-23 拍板记入）
- **Won't**：自动选课/抢课；全学位路径优化求解；研究生课表抓取（官方不公开）

## 验收标准

1. 检索层：金标查询 recall@5 / MRR@5 达标——**D1 实测基线已拍板**：15 条金标 hybrid(e3) recall@5 = 1.00 / MRR@5 = 0.92 / nDCG@5 = 0.92，D4 复核阈值 recall@5 ≥ 0.90 且 MRR@5 ≥ 0.85。**D4 复核（2026-10-24，201 卡）**：hybrid(e3) recall@5 = 1.000 / MRR@5 = 0.878 / nDCG@5 = 0.887，达标。
2. 端到端：20 条评估集实测准确率与响应时间——**D4 基线 12/20 = 60.0%；D4.1（v1 判据）17/20 = 85.0%，单轮中位 25.44s；D4.2（v2 判据修订）19/20 = 95.0%，单轮中位 33.41s / P90 105.95s（Q16 单次遗漏，定向修复 PASS 未计入全量）**；**简历口径用户已拍板保持现状（87%/18s），AI 不改**；实测与简历口径的差异记录在 04 §7（实测为准，不造假，不砍审查/精炼链路）。
3. 三板斧全链路可验证：抽查回答均附来源、无来源则明说
4. CCA 学位规则校验可溯源（官网 Programme Structure，规则原文见 decisions.md）
