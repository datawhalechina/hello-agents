===============================================================================
                            下一步操作
===============================================================================

步骤 1: 激活虚拟环境
---------------------
Windows PowerShell:
    .\venv_hello_agents\Scripts\Activate.ps1

Windows CMD:
    venv_hello_agents\Scripts\activate.bat

macOS/Linux:
    source venv_hello_agents/bin/activate

如果 PowerShell 提示权限错误，执行：
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser


步骤 2: 安装依赖包
---------------------
选项 A - 完整安装（推荐，适合学习所有章节）:
    pip install -r requirements.txt

选项 B - 精简安装（适合快速开始）:
    pip install -r requirements-minimal.txt

选项 C - 使用国内镜像加速:
    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple


步骤 3: 配置 API 密钥
---------------------
1. 复制环境变量模板（如果还没有 .env 文件）:
   copy .env.example .env  (Windows)
   cp .env.example .env    (macOS/Linux)

2. 编辑 .env 文件，填入真实的 API 密钥:
   - OPENAI_API_KEY (必需)
   - TAVILY_API_KEY (第1章、第4章需要)
   - AMAP_API_KEY (第13章需要)

API 密钥获取方式请参考 INSTALLATION_GUIDE.md


步骤 4: 验证安装
---------------------
运行测试脚本:
    python test_installation.py

如果所有检查都通过，您就可以开始学习了！

===============================================================================
                           常见问题
===============================================================================

Q1: pip install 速度很慢怎么办？
A1: 使用国内镜像源：
    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

Q2: 提示 hello-agents 找不到？
A2: 确保虚拟环境已激活，然后重新安装：
    pip install "hello-agents[all]>=0.2.7"

Q3: API 调用失败？
A3: 检查 .env 文件中的 API 密钥是否正确配置

Q4: 需要 GPU 运行 Transformer 吗？
A4: 第3章和第11章建议使用 GPU，其他章节 CPU 即可

Q5: 如何获取更多帮助？
A5: 
    - 查看 INSTALLATION_GUIDE.md 详细说明
    - 访问在线文档: https://datawhalechina.github.io/hello-agents/
    - 提交 Issue: https://github.com/datawhalechina/hello-agents/issues
