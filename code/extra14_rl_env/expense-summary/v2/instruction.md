# 汇总报销明细

请编写 `/app/summarize.py`，用 Python 标准库实现报销明细汇总。程序接收三个位置参数：输入 CSV 路径、汇总 CSV 输出路径、复核明细 CSV 输出路径。输入文件包含 `日期`、`姓名`、`类别`、`金额` 四列。

然后用该程序处理 `/app/input.csv`，在 `/app/` 下生成以下两个 UTF-8 CSV 文件：

1. `summary.csv`：按姓名汇总报销总额，列名为 `姓名`、`报销总额`。每个人只出现一行，按其在输入中首次出现的顺序排列；金额保留两位小数。
2. `over_500.csv`：列名和列顺序与输入相同，只保留金额严格大于 500 元的原始记录，并按输入中的顺序排列。金额等于 500 元的记录不包含在内。
