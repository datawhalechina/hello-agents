## RAGTool 概述  

`RAGTool` 是 HelloAgents 框架提供的**开箱即用的 RAG（检索增强生成）工具**，它将以下组件封装为一个统一接口：

| 组件 | 功能 |
|-----|------|
| **向量存储** | 管理知识库文档的存储和索引 |
| **嵌入模型** | 将文本转换为向量表示 |
| **大语言模型** | 基于检索结果生成自然语言答案 |
| **文档处理器** | 支持多种格式（PDF、Word、Markdown 等）的解析和分块 |

### 初始化方式

```python
from hello_agents.tools import RAGTool

# 基础初始化
rag_tool = RAGTool(
    knowledge_base_path="./my_kb",      # 知识库存储路径
    rag_namespace="my_project"          # 命名空间（隔离不同项目）
)
```

## search vs ask 对比

| 特性 | `search` | `ask` |
|-----|----------|-------|
| **功能** | 仅执行向量检索 | 检索 + LLM 生成 |
| **输入** | `query` (查询词) | `question` (问题) |
| **返回值** | 原始文档片段列表 | 自然语言答案 |
| **是否调用 LLM** | ❌ 否 | ✅ 是 |
| **使用场景** | 查看原始检索内容、调试 | 获取完整回答 |

### 代码对比

```python
# ========== search: 仅检索 ==========
results = rag_tool.run({
    "action": "search",
    "query": "深度学习应用场景",
    "limit": 3
})
print(results)
# 输出: 原始文档片段文本...

# ========== ask: 检索 + 生成 ==========
answer = rag_tool.run({
    "action": "ask",
    "question": "深度学习有哪些应用场景？",
    "limit": 3
})
print(answer)
# 输出: "深度学习在多个领域有广泛应用，包括图像识别、自然语言处理..."
```

## 高级参数说明

### `ask` 操作支持的参数

```python
answer = rag_tool.run({
    "action": "ask",
    "question": "...",              # 必填：用户问题
    "limit": 4,                     # 可选：检索片段数量 (默认: 3)
    "include_citations": True,      # 可选：是否包含引用来源 (默认: False)
    "max_chars": 1500,              # 可选：答案最大长度限制
    "enable_advanced_search": True  # 可选：启用高级检索策略
})
```

### 参数详解

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `question` | str | 必填 | 用户的问题 |
| `limit` | int | 3 | 从知识库检索的相关文档片段数量 |
| `include_citations` | bool | False | 是否在答案末尾添加引用来源信息 |
| `max_chars` | int | None | 答案的最大字符数限制 |
| `enable_advanced_search` | bool | False | 启用 HyDE、多查询扩展等高级检索策略 |

## 使用示例

### 示例 1：基础问答

```python
from hello_agents.tools import RAGTool
from dotenv import load_dotenv
load_dotenv()


### 核心功能讲解！！！！！


# 初始化 RAGTool
rag_tool = RAGTool(
    knowledge_base_path="./kb",
    rag_namespace="demo"
)

# 添加知识文档  --  自动把文档分块，做向量嵌入！！！！
rag_tool.run({
    "action": "add_text",
    "text": "深度学习是机器学习的一个子领域...",
    "document_id": "dl_intro"
})

# 执行问答  --  搜索相关内容，并集成至上下文当中，然后调用LLM做回答！！！！
answer = rag_tool.run({
    "action": "ask",
    "question": "什么是深度学习？"
})
print(answer)
```

answer = rag_tool.run({

## 关键要点总结

1. **RAGTool 是开箱即用的**：内部封装了向量存储、嵌入模型和 LLM，无需额外配置

2. **`search` vs `ask` 的区别**：
   - `search` = 仅检索原始片段
   - `ask` = 检索 + 自动构建上下文 + LLM 生成

3. **上下文自动构建**：`ask` 操作会自动将检索结果整合到 Prompt 中，无需手动拼接

4. **可配置性**：支持引用标注、检索数量、高级检索策略等参数

5. **流式处理**：内部自动处理文档解析、分块、向量化、检索、生成的完整流程
