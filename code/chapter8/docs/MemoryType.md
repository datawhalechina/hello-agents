# 四种记忆类型详解

HelloAgents 模拟人类记忆系统，提供四种专业记忆类型。

---

## 一、四种记忆整体架构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         HelloAgents 记忆系统架构                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   用户查询 → MemoryTool → MemoryManager → 选择合适的记忆类型 → 执行检索       │
│                                                                             │
│   ┌─────────────────┬─────────────────┬─────────────────┬─────────────────┐ │
│   │   工作记忆       │    情景记忆      │    语义记忆      │    感知记忆     │ │
│   │  WorkingMemory  │ EpisodicMemory  │ SemanticMemory  │ PerceptualMemory│ │
│   ├─────────────────┼─────────────────┼─────────────────┼─────────────────┤ │
│   │ • 临时信息      │ • 事件经历      │ • 概念知识      │ • 多模态数据    │ │
│   │ • 对话上下文    │ • 时间序列      │ • 实体关系      │ • 图片/音频     │ │
│   │ • 任务状态      │ • 会话关联      │ • 知识图谱      │ • 跨模态检索    │ │
│   ├─────────────────┼─────────────────┼─────────────────┼─────────────────┤ │
│   │ 纯内存存储      │ SQLite+Qdrant   │ Neo4j+Qdrant    │ 分模态向量存储  │ │
│   │ 容量: 50条      │ 持久化存储      │ 长期存储        │ 动态管理        │ │
│   │ TTL: 60分钟     │ 支持时间检索    │ 支持图推理      │ CLIP/CLAP编码   │ │
│   └─────────────────┴─────────────────┴─────────────────┴─────────────────┘ │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## 二、四种记忆对比速查

| 特性 | 工作记忆 | 情景记忆 | 语义记忆 | 感知记忆 |
|------|---------|---------|---------|---------|
| **存储内容** | 临时信息 | 事件经历 | 概念知识 | 多模态数据 |
| **存储方案** | 纯内存 | SQLite + Qdrant | Neo4j + Qdrant | 分模态向量存储 |
| **容量** | 有限（默认50条） | 几乎无限 | 几乎无限 | 动态管理 |
| **生命周期** | TTL自动过期（60分钟） | 持久化 | 长期存储 | 按重要性管理 |
| **检索速度** | ⚡ 极快 | 🚀 快 | 🚀 快 | 🚀 快 |
| **核心检索方式** | TF-IDF + 关键词 | 向量 + 时间 | 向量 + 图 | 模态专用编码 |

## 三、工作记忆（Working Memory）

### 3.1 特点
- **纯内存存储**：访问速度最快，重启后丢失
- **容量有限**：默认最多50条，超出时自动淘汰低重要性记忆
- **TTL机制**：60分钟自动过期清理

### 3.2 检索流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     工作记忆检索流程                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  用户查询: "Python数据处理"                                      │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 1: TF-IDF向量化                                     │    │
│  │  查询分词 → 计算词频 → 生成TF-IDF向量                     │    │
│  │  "Python": 高权重, "数据处理": 高权重                     │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 2: 语义相似度计算 (TF-IDF)                          │    │
│  │                                                         │    │
│  │  M1: "用户正在学习Python的pandas库"                      │    │
│  │      → TF-IDF相似度: 0.85 (含"Python")                  │    │
│  │                                                         │    │
│  │  M2: "用户安装了numpy包"                                │    │
│  │      → TF-IDF相似度: 0.20 (无关)                        │    │
│  │                                                         │    │
│  │  M3: "用户询问数据分析的问题"                            │    │
│  │      → TF-IDF相似度: 0.75 ("数据分析"语义相近)          │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 3: 关键词匹配 (兜底策略)                            │    │
│  │                                                         │    │
│  │  M1: 匹配"Python" → 关键词得分: 0.5                     │    │
│  │  M2: 无匹配 → 关键词得分: 0                             │    │
│  │  M3: 匹配相关词 → 关键词得分: 0.2                       │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 4: 时间衰减计算                                      │    │
│  │                                                         │    │
│  │  公式: 时间衰减 = exp(-经过时间/60分钟)                   │    │
│  │                                                         │    │
│  │  M1 (5分钟前):  exp(-5/60)  = 0.92                      │    │
│  │  M2 (30分钟前): exp(-30/60) = 0.61                      │    │
│  │  M3 (2分钟前):  exp(-2/60)  = 0.97                      │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 5: 综合评分                                          │    │
│  │                                                         │    │
│  │  公式: 最终得分 = (TF-IDF×0.7 + 关键词×0.3) × 时间衰减 × 重要性权重 │    │
│  │                                                         │    │
│  │  重要性权重 = 0.8 + 重要性×0.4                          │    │
│  │                                                         │    │
│  │  M1: (0.85×0.7 + 0.5×0.3) × 0.92 × (0.8+0.8×0.4) = 0.767 │    │
│  │  M2: (0.20×0.7 + 0×0.3) × 0.61 × (0.8+0.6×0.4)   = 0.089 │    │
│  │  M3: (0.75×0.7 + 0.2×0.3) × 0.97 × (0.8+0.7×0.4) = 0.613 │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  返回排序: M1 (0.767) > M3 (0.613) > M2 (0.089)                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.3 评分公式

```
最终得分 = (TF-IDF相似度×0.7 + 关键词匹配×0.3) × 时间衰减 × (0.8 + 重要性×0.4)
```

| 因素 | 权重 | 说明 |
|------|------|------|
| TF-IDF相似度 | 70% | 语义相似度，主要因素 |
| 关键词匹配 | 30% | 兜底策略，确保召回 |
| 时间衰减 | 动态 | 新记忆得分更高 |
| 重要性权重 | 0.8~1.2 | 调节因子，避免过度影响 |

### 3.4 适用场景
- 当前对话的临时上下文
- 任务执行中的中间状态
- 短时提醒信息

## 四、情景记忆（Episodic Memory）

### 4.1 特点
- **混合存储**：SQLite存结构化数据，Qdrant存向量
- **时间序列**：保留事件发生的时间顺序
- **会话关联**：支持按会话ID检索相关事件

### 4.2 检索流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     情景记忆检索流程                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  用户查询: "Python学习进度"                                      │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 1: 结构化预过滤                                      │    │
│  │                                                         │    │
│  │  过滤条件: 最近3天的记录                                  │    │
│  │                                                         │    │
│  │  E1: "学习Python基础语法" (3天前)  → 过滤掉 ❌           │    │
│  │  E2: "完成爬虫项目" (2天前)        → 保留 ✓             │    │
│  │  E3: "复习pandas" (1天前)          → 保留 ✓             │    │
│  │  E4: "学习机器学习" (5小时前)      → 保留 ✓             │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 2: 向量语义检索                                      │    │
│  │                                                         │    │
│  │  查询向量化 → 与候选记忆计算余弦相似度                    │    │
│  │                                                         │    │
│  │  E2: "完成爬虫项目" → 相似度: 0.75 (Python应用)         │    │
│  │  E3: "复习pandas" → 相似度: 0.88 (直接相关)             │    │
│  │  E4: "学习机器学习" → 相似度: 0.70 (Python相关)         │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 3: 时间近因性计算                                    │    │
│  │                                                         │    │
│  │  公式: 时间近因性 = 1 / (1 + ln(1 + 经过天数))            │    │
│  │                                                         │    │
│  │  E2 (2天前):  1 / (1 + ln(3)) = 0.52                    │    │
│  │  E3 (1天前):  1 / (1 + ln(2)) = 0.59                    │    │
│  │  E4 (5小时):  1 / (1 + ln(0.21)) = 0.95                 │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 4: 综合评分                                          │    │
│  │                                                         │    │
│  │  公式: 最终得分 = (向量相似度×0.8 + 时间近因性×0.2) × 重要性权重 │    │
│  │                                                         │    │
│  │  E2: (0.75×0.8 + 0.52×0.2) × (0.8+0.9×0.4) = 0.817      │    │
│  │  E3: (0.88×0.8 + 0.59×0.2) × (0.8+0.7×0.4) = 0.888      │    │
│  │  E4: (0.70×0.8 + 0.95×0.2) × (0.8+0.85×0.4) = 0.855     │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  返回排序: E3 (0.888) > E4 (0.855) > E2 (0.817)                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.3 评分公式

```
最终得分 = (向量相似度×0.8 + 时间近因性×0.2) × (0.8 + 重要性×0.4)
```

| 因素 | 权重 | 说明 |
|------|------|------|
| 向量相似度 | 80% | 语义相关性 |
| 时间近因性 | 20% | 越近的事件得分越高 |
| 重要性权重 | 0.8~1.2 | 调节因子 |

### 4.4 适用场景
- 用户历史操作记录
- 学习历程追踪
- 事件时间线回溯

## 五、语义记忆（Semantic Memory）

### 5.1 特点
- **知识图谱**：使用Neo4j存储实体和关系
- **自动提取**：自动识别内容中的实体和关系
- **混合检索**：向量检索 + 图检索 + 推理

### 5.2 知识图谱示例

```
存储的知识: "Python是一种编程语言，常用于数据分析"

提取的实体和关系:

    ┌──────────────┐         ┌──────────────┐
    │    Python    │◄───────►│   编程语言    │
    │   (实体)     │ is_a    │   (概念)     │
    └──────┬───────┘         └──────────────┘
           │
           │ used_for
           ↓
    ┌──────────────┐
    │   数据分析    │
    │   (应用)     │
    └──────────────┘
```

### 5.3 检索流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     语义记忆检索流程                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  用户查询: "Python数据处理工具"                                  │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 1: 向量检索 (Qdrant)                                │    │
│  │                                                         │    │
│  │  查询向量化 → 计算与知识内容的相似度                      │    │
│  │                                                         │    │
│  │  S1: "Python是编程语言，用于数据分析" → 相似度: 0.82      │    │
│  │  S2: "pandas是Python的数据处理库" → 相似度: 0.91        │    │
│  │  S3: "机器学习是AI分支" → 相似度: 0.45                  │    │
│  │  S4: "用户喜欢用Python做数据可视化" → 相似度: 0.78      │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 2: 图检索 (Neo4j)                                   │    │
│  │                                                         │    │
│  │  查询实体: "Python", "数据处理"                           │    │
│  │                                                         │    │
│  │  在知识图谱中查找相关实体和关系:                          │    │
│  │                                                         │    │
│  │  S1: 含"Python"和"数据分析" → 图相似度: 0.85            │    │
│  │  S2: 含"pandas"(关联Python)和"数据处理" → 图相似度: 0.95 │    │
│  │  S3: 无相关实体 → 图相似度: 0.10                        │    │
│  │  S4: 含"Python" → 图相似度: 0.60                        │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 3: 混合评分                                          │    │
│  │                                                         │    │
│  │  基础相关性 = 向量相似度×0.7 + 图相似度×0.3              │    │
│  │                                                         │    │
│  │  S1: 0.82×0.7 + 0.85×0.3 = 0.829                        │    │
│  │  S2: 0.91×0.7 + 0.95×0.3 = 0.922                        │    │
│  │  S3: 0.45×0.7 + 0.10×0.3 = 0.345                        │    │
│  │  S4: 0.78×0.7 + 0.60×0.3 = 0.726                        │    │
│  │                                                         │    │
│  │  最终得分 = 基础相关性 × (0.8 + 重要性×0.4)              │    │
│  │                                                         │    │
│  │  S1: 0.829 × 1.16 = 0.962                               │    │
│  │  S2: 0.922 × 1.14 = 1.051 ← 最高 (pandas直接相关)       │    │
│  │  S3: 0.345 × 1.12 = 0.386                               │    │
│  │  S4: 0.726 × 1.10 = 0.799                               │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  返回排序: S2 > S1 > S4 > S3                                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 5.4 评分公式

```
最终得分 = (向量相似度×0.7 + 图相似度×0.3) × (0.8 + 重要性×0.4)
```

| 因素 | 权重 | 说明 |
|------|------|------|
| 向量相似度 | 70% | 语义相关性，主要因素 |
| 图相似度 | 30% | 关系推理，发现概念关联 |
| 重要性权重 | 0.8~1.2 | 调节因子 |

### 5.5 适用场景
- 用户偏好和属性
- 领域知识存储
- 概念关系推理

## 六、感知记忆（Perceptual Memory）

### 6.1 特点
- **模态分离**：不同模态数据分开存储，避免维度不匹配
- **跨模态检索**：可用文本搜索图片内容
- **专用编码器**：CLIP处理图像，CLAP处理音频

### 6.2 模态编码器

| 模态 | 编码器 | 输出维度 | 说明 |
|------|--------|---------|------|
| 文本 | 文本嵌入模型 | 768/1024维 | 语义向量 |
| 图像 | CLIP | 512维 | 视觉特征向量 |
| 音频 | CLAP | 512维 | 音频特征向量 |

### 6.3 跨模态检索流程（文本搜图片）

```
┌─────────────────────────────────────────────────────────────────┐
│                   感知记忆跨模态检索流程                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  用户查询（文本）: "编程代码"                                    │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 1: 文本编码                                          │    │
│  │                                                         │    │
│  │  "编程代码" → 文本编码器 → 向量 [0.12, -0.45, ...]      │    │
│  │                    ↓                                     │    │
│  │              CLIP文本编码器                              │    │
│  │                    ↓                                     │    │
│  │         统一向量空间 (512维)                            │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ Step 2: 图片向量比对                                      │    │
│  │                                                         │    │
│  │  P1: 猫的图片 → CLIP编码 → [0.23, 0.15, ...]            │    │
│  │            与查询相似度: 0.15 ❌                         │    │
│  │                                                         │    │
│  │  P2: 代码截图 → CLIP编码 → [0.18, -0.42, ...]           │    │
│  │            与查询相似度: 0.92 ✓                          │    │
│  │                                                         │    │
│  │  P3: 数据图表 → CLIP编码 → [0.31, 0.08, ...]            │    │
│  │            与查询相似度: 0.45                            │    │
│  └─────────────────────────────────────────────────────────┘    │
│                    ↓                                             │
│  返回排序: P2 (0.92) > P3 (0.45) > P1 (0.15)                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 6.4 适用场景
- 图片内容记忆
- 音频转录存储
- 多模态关联检索

## 七、检索策略速查表

| 记忆类型 | 核心检索方式 | 特殊因素 | 权重分配 |
|---------|-------------|---------|----------|
| 工作记忆 | TF-IDF + 关键词 | 时间衰减（分钟级） | 语义0.7 + 关键词0.3 |
| 情景记忆 | 向量检索 | 时间近因性（天级） | 相似度0.8 + 时间0.2 |
| 语义记忆 | 向量 + 图检索 | 关系推理 | 向量0.7 + 图0.3 |
| 感知记忆 | 模态专用编码 | 跨模态匹配 | 向量相似度 |

```
┌─────────────────────────────────────────────────────────────┐
│                      记忆类型选择决策树                        │

│  需要存储什么内容？                                          │
│                    ↓                                         │
│     ┌──────────────┼──────────────┐                         │
│     ↓              ↓              ↓                         │
│  临时信息       事件记录        知识概念                     │
│     ↓              ↓              ↓                         │
│  工作记忆       情景记忆        语义记忆                     │

│                                                             │

│               图片/音频                                      │
```
