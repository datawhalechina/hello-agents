## 1. 背景概览

际华集团股份有限公司（股票代码：601718）是中国新兴际华集团旗下核心上市公司，主要从事军需品、职业装、防护装备等纺织类产品的生产与销售。作为军工纺织行业的龙头企业之一，际华集团兼具国防军工概念与纺织服装双重属性，其经营业绩受国防预算、军品采购政策及民用市场需求多重因素影响。本报告旨在梳理公司基本面、股价走势、行业竞争格局及机构观点，为投资决策提供参考依据。
